One line of weather for Drizzlewick, a city that doesn't exist: light rain, 11°, and the 8:04 bus running fashionably late — so the bored commuter at the bus stop gets a forecast that reads like a real broadcast, bent just enough to smile at, with the practical advice to bring an umbrella and low expectations.

## Run it

```sh
python3 main.py
```

Writes the 122-character forecast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Python 3.13, standard library only, no network, deterministic.
